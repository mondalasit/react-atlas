# React Atlas v1.3 Release Notes

## 🚀 React Atlas v1.3

**Codename:** Route Intelligence Release

React Atlas v1.3 builds upon the Architecture Intelligence platform introduced in v1.2 by adding route analysis, improving the dashboard experience, and making project insights easier to understand.

---

## ✨ What's New

### 🛣 Route Discovery

React Atlas now discovers application routes during analysis.

Supported route types include:

- Static routes
- Nested routes
- Dynamic routes (where supported)

The dashboard now provides an overview of every discovered route in the project.

---

### 📊 Improved Dashboard

The dashboard has been redesigned for better readability.

Improvements include:

- Cleaner layout
- Improved information hierarchy
- Better spacing
- Simplified summary cards
- Enhanced sidebar experience

---

### 🧠 Enhanced Architecture Insights

Architecture Insights now present project information in a much cleaner format.

Highlights include:

- Root Components
- Leaf Components
- Dead Components
- Most Imported Components

Insights are easier to scan and understand even for larger projects.

---

### 📈 Route Summary

Route Discovery now includes summary metrics such as:

- Total Routes
- Static Routes
- Dynamic Routes

This provides a quick overview of application navigation.

---

### 🔄 Circular Dependency Improvements

Circular dependency visualization has been improved with a cleaner dashboard presentation.

Developers can quickly identify problematic dependency cycles.
